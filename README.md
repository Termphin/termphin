# Termphin

Bug reports and ideas for [Termphin](https://termphin.dev), an SSH client whose
sessions survive a dropped connection. The app's source code is not in this
repository.

- [Report a bug](../../issues/new?template=bug_report.yml)
- [Suggest an idea](../../issues/new?template=idea.yml)
- [Read the manual](https://termphin.dev/docs/)
- [See the changelog](https://termphin.dev/changelog)

Before you open an issue, search the existing ones. If yours is already there,
add a comment instead.

Never paste a private key or password. To hide hostnames and usernames in
screenshots, turn on **Anonymize** in Settings.

Found a vulnerability? Do not open an issue. See [SECURITY.md](SECURITY.md).

## Related repositories

- [terminal_view](https://github.com/Termphin/terminal_view): the terminal widget
- [termphin-agent](https://github.com/Termphin/termphin-agent): the server helper that keeps sessions alive
